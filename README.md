# sanawarmalik.com

My personal portfolio — projects, experience, and what I get up to outside school.

Live at **[sanawarmalik.com](https://sanawarmalik.com)**.

## What's here

A single static page. No build step, no framework, no dependencies.

- `index.html` — the whole site: markup, styles and scripts in one file
- `img/` — photographs, diagrams and two short clips

Navigation is hash-based: the project write-ups and the "Outside of work"
page are separate views inside the same document, shown and hidden by the
router at the bottom of the file.

## Editing it

Open `index.html` in any editor, change the text, save, and open the file in
a browser to check it. Commit and push, and Vercel redeploys on its own.
